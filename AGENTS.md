# Agent instructions

Shared by all coding agents (Claude Code, Codex). `CLAUDE.md` imports this
file.

## Project

bs-option-pricing: Mini-project derivation and application of BS formula and Vasiciek model for euro-call pricing.

## Workflow

- At session start, read `TASKS.md`.
- Before starting a task, set its status to `in progress` and `owner` to
  your agent name (`claude` or `codex`). Do not take tasks owned by another
  agent.
- When finished, move it to Done and add any follow-up tasks you discover.
- Work on your own branch or git worktree; do not commit to `main` directly.

## Conventions

- Markdown: sections start at heading level 2, blank lines between headings,
  body text and equations, wrap at 79 characters.
- Use normal dashes (-), never em dashes.
- Ask before installing packages or changing config files.
- Never add AI co-author lines to commits or documents.
